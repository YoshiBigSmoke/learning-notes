# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Personal learning notes and practice code. No build system, no test suite, no CI. See README.md for a full description of each section.

## Structure

Each language has its own folder with a `basics.txt` note file. The only runnable code is:

- `C/calculator.c` — compile with `gcc calculator.c -o calculator && ./calculator`
- Any Rust snippets from `Rust/basics.txt` — run with `cargo run` inside a Cargo project

## Conventions

- Notes written in English; code output and comments in Spanish.
- `@(note)` and `% importante %` mark warnings worth paying attention to.
- Dates at the top of files use `YYYY-MM-DD`.
